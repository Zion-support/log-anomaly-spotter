# Log Anomaly Spotter

Upload logs and detect anomalies, error spikes, and unusual patterns before they become incidents.

**Live app:** https://zion-support.github.io/log-anomaly-spotter/

## Features
- Automatic error-spike and pattern detection across large log files
- Anomaly scoring with severity ranking
- Timeline view to correlate spikes with deploys and incidents
- Exportable findings for postmortems and SLO reviews
